## ⚡ QUICK START (30 segundos)

1. **Abra** `index.html` em seu navegador
2. **Login** com `dev` / `dev123`
3. **Vá em Cadastro** → Adicione um produto

## 🎯 FUNCIONALIDADES PRINCIPAIS

### 📊 ABAS
```
1. Cadastro     → Adicionar novos produtos
2. Gráficos     → Ver vendas + Sugestões de pedidos
3. Tabela       → Listar todos os produtos
4. Relatórios   → Filtrar + Exportar dados
5. Usuários     → Criar novos usuários (dev only)
6. Perfil       → Editar dados + Foto
```

### 💾 DADOS
Tudo é salvo automaticamente no seu navegador (localStorage)

### 📁 FORMATOS DE EXPORTAÇÃO
- **Excel** → Clique "Excel / CSV" (arquivo `.xlsx`)
- **PDF** → Clique "PDF" (relatório profissional)

### 📸 FOTO DO PERFIL
- Vá em **Perfil**
- Clique em **"Trocar Foto"**
- Selecione uma imagem
- A foto aparece no header automaticamente!

### 💡 SUGESTÕES INTELIGENTES
Em **Gráficos**, veja recomendações automáticas:
- Produtos com menos estoque aparecem como "URGENTE" 🔴
- Sistema sugere quantidade para novo pedido
- Atualiza em tempo real ao adicionar produtos

## 🐛 PROBLEMAS COMUNS?

### Foto não atualiza?
```
→ Limpe cache: Ctrl+Shift+Delete
→ Recarregue a página: Ctrl+R
```

### Exportação não funciona?
```
→ Adicione produtos antes de exportar
→ Tente outro navegador
```

### Filtros não encontram dados?
```
→ Limpe os filtros
→ Escreva o nome exato do produto
```

### Dados sumiram?
```
→ Limpar localStorage apaga TUDO
→ localStorage é local do navegador (não sincroniza entre abas)
```
