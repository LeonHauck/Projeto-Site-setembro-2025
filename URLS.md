## ⚡ Atalhos Úteis

- **Próxima aba**: Clique em uma aba
- **Aba anterior**: Clique no botão ◀ do navegador
- **Próxima aba**: Clique no botão ▶ do navegador
- **Recarregar**: F5 ou Ctrl+R (mantém a aba)

---

## ✨ Recurso: Deep Linking

Você pode criar links diretos para abas:

```html
<a href="#cadastro">Adicionar Produto</a>
<a href="#graficos">Ver Gráficos</a>
<a href="#relatorios">Exportar Relatório</a>
```

---

## 💾 Salve em Favoritos!

1. Abra uma aba (ex: Gráficos)
2. Pressione: **Ctrl+D** (Chrome/Firefox) ou **Cmd+D** (Mac)
3. Salve com nome descritivo
4. Clique para abrir direto naquela aba!
