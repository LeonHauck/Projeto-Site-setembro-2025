R: Localmente no seu navegador (localStorage)

**P: Posso usar em outro computador?**  
R: Não, dados são específicos deste navegador

**P: Posso compartilhar com outros usuários?**  
R: Sim! Use diferentes credenciais (dev/gestor/func)

**P: Como faço backup?**  
R: Exporte para Excel regularmente

**P: Posso editar depois de adicionar?**  
R: Sim! Aba Tabela → Clique no ✏️

**P: Meus dados sumiram!**  
R: Provavelmente o cache foi limpo. Adicione novamente.

## 🆘 Problemas Comuns & Soluções

### Página em branco ao abrir
**Solução**: 
1. Clique direito → Inspecionar
2. Veja se há erro na aba Console
3. Tente em outro navegador

### Edição não funciona
**Solução**:
1. Verifique se está em `index.html`
2. Recarregue a página (F5)
3. Tente novamente

### Dados não salvam
**Solução**:
1. Verifique se localStorage não foi limpado
2. Abra Dev Tools (F12) → Application → localStorage
3. Verifique se há dados salvos

### Modal não abre
**Solução**:
1. Verifique se tem produtos na tabela
2. Recarregue a página
3. Clique no ✏️ novamente
